Real FPGA implementation

What would run on the FPGA board?

In a real FPGA project, these separate Verilog modules are connected together in one top-level design.

MODULE 01

clock_divider.v

Converts the 50 MHz board clock into one clean pulse per second.

MODULE 02

stopwatch_fsm.v

Controls Start, Stop, Reset, and Lap button states.

MODULE 03

time_counter.v

Counts seconds from 00 to 59, then increases the minute counter.

MODULE 04

seven_segment.v

Converts each number into the seven LED segment output pattern.
